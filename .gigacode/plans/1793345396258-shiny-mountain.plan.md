# План: Футуристичный сайт электрощитов на React

## Стек технологий
- **Vite + React + JavaScript** — быстрая сборка
- **Tailwind CSS** — стилизация, тёмная тема
- **MUI v5** — компоненты (кнопки, формы, диалоги)
- **Framer Motion** — анимации (scroll, hover, entrance)
- **React Router v6** — навигация
- **Lucide React** — иконки

## Дизайн-система
| Токен | Цвет | Назначение |
|-------|------|------------|
| electric | `#00d4ff` | Основной акцент, CTA |
| cyan | `#00f0ff` | Вторичный акцент |
| background-deep | `#0a0e1a` | Фон страницы |
| background-card | `#141b2d` | Фон карточек |
| text-primary | `#ffffff` | Основной текст |
| text-secondary | `#a0aec0` | Вторичный текст |

**Ключевые эффекты:** glassmorphism, gradient text, floating shapes, scroll animations, animated counters, micro-interactions

## Последовательность реализации

### Фаза 1: Фон (7 шагов)
1. Очистка старых файлов, инициализация Vite
2. Установка зависимостей: react, react-dom, react-router-dom, @mui/material, @emotion/react, framer-motion, tailwindcss, lucide-react
3. Настройка vite.config.js, tailwind.config.js, postcss.config.js
4. Создание index.html с Google Fonts (Inter)
5. Создание src/index.css с Tailwind + кастомные утилиты (glass, gradient, bg-grid)
6. Создание src/theme.js (MUI dark theme)
7. Создание src/main.jsx с ThemeProvider

### Фаза 2: Базовые компоненты (4 шага)
8. src/App.jsx + src/pages/HomePage.jsx
9. src/components/Layout.jsx
10. src/components/ui/ — 5 переиспользуемых компонентов
11. src/components/Header.jsx (fixed nav, scroll-aware glassmorphism, mobile menu)

### Фаза 3: Секции страницы (8 шагов)
12. Hero.jsx — full-screen, animated shapes, stats counters, 2 CTA
13. Services.jsx — 4 карточки услуг (проектирование, сборка, маркировка, монтаж)
14. PanelTypes.jsx — 5 типов щитов (вводные, распределительные, учета, силовые, слаботочные)
15. Advantages.jsx — 6 преимуществ + AnimatedCounter статистика
16. Gallery.jsx — сетка работ с hover overlay + lightbox
17. OrderForm.jsx — форма заказа с валидацией + success state
18. Contacts.jsx — контакты + карта (iframe)
19. Footer.jsx — навигация + контакты + копирайт

### Фаза 4: Финальная полировка
20. Адаптивность (mobile/tablet/desktop)
21. Тестирование всех анимаций
22. Проверка сборки: npm run build

## Контент (на основе nsk-elektrik.ru)
- Hero: "Электрощиты на заказ в Новосибирске"
- Услуги: проектирование, сборка, маркировка, монтаж
- Типы: ВРУ, РЩ, ЩУ, силовые, слаботочные
- Преимущества: индивидуальный подход, качественные комплектующие (ABB, Schneider), сроки, гарантия 3 года, доставка по России
- Галерея: портфолио работ
- Форма заказа: имя, телефон, email, тип щита, комментарий
